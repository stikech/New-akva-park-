## Что сделано

### Оплата через Kaspi
- Номер Kaspi — `backend/payment.config.js` (`kaspiPhone`) или переменная `KASPI_PHONE` в Render.
  Пока пусто — онлайн-оплата выключена, сайт предлагает оплатить на кассе.
- Схема: заказ → клиент видит сумму, номер и код `NP-XXXXX` → переводит в Kaspi с кодом в комментарии →
  «Я оплатил» → уведомление в Telegram → админ в `/admin` → «Оплаты» → «Подтвердить» / «Отклонить».
- Автоподтверждения нет: API Kaspi выдаётся только по договору Kaspi Pay. Точка встраивания —
  `POST /api/admin/{orders|visits}/:id/confirm`.
- Код: `backend/src/kaspi.js`, `payments.js` (абонементы), `visits.js` (билеты), фронт —
  `frontend/assets/js/modules/kaspi-pay.js`.

### Критическое исправление
Прежняя «оплата картой» была эмулятором: любая карта по Луну (4242…) выдавала билет без денег.
Теперь эмулятор работает только при `PAYMENT_MODE=demo` (для тестов).

### Магазин абонементов — `/shop`
- Группы: **Тренажёрный зал** (Дневной, Вечерний, «Золотая» карта), **Бассейн**, **Групповые программы**.
  Тарифы берутся из `frontend/assets/js/config/site-data.js` (`backend/src/memberships.js`).
- Гость нажимает «Купить» → вход/регистрация → возврат на `/shop?plan=…`, окно покупки открывается само.
- Тот же магазин есть в кабинете: `/account/shop`.

### Публичная оферта — `/offer`
- Перед любой оплатой обязательна галочка: оферта + правила посещения + согласие на обработку
  персональных данных. Сервер без неё не создаёт заказ (422) и сохраняет время согласия (`consentAt`).
- Реквизиты продавца: `sellerName`, `sellerBin` в `backend/payment.config.js` (сейчас пусто).
- Текст оферты — шаблон, **его стоит показать юристу**.

### Страницы и навигация
- Каждый пункт меню — отдельная страница: `/slides`, `/prices`, `/shop`, `/rules`, `/fitness`,
  `/classes`, `/spa`, `/pool`, `/contacts`. Плюс `/ticket` («Мои билеты», код для входа) и `/offer`.
- Навигация: только верхнее меню и кнопки «Назад / Дальше» внизу страницы
  (хлебные крошки, плитки на главной и меню в подвале убраны по просьбе).
- Исправлено: на главной дважды выводился блок с цифрами.
- Исправлено: после возврата из кабинета шапка показывала «Войти» — теперь показывает имя и
  перепроверяет вход при возврате кнопкой «назад».

### Хранение данных
Бесплатный диск Render стирается при перезапуске. Добавлена облачная копия в Upstash Redis
(`backend/src/cloud-backup.js`): включается переменными `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

## Что осталось сделать (Render → сервис → Environment)

1. **`KASPI_PHONE`** — номер Kaspi аквапарка (без него оплата выключена).
2. **`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`** — upstash.com → Create Database → REST API.
   Без них аккаунты, заказы и билеты пропадают при каждом «засыпании» сервера. **Самое важное.**
3. **`PAYMENT_SECRET`** — любая длинная случайная строка (подписи чеков).
4. ~~**`DEMO_ACCOUNTS=0`**~~ — сделано 6.11, демо-входы на рабочем сайте выключены.
5. По желанию: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — уведомления «клиент оплатил».
6. По желанию: `sellerName` / `sellerBin` в `backend/payment.config.js` — реквизиты в оферте.
7. ~~Выкатить последний коммит на Render~~ — сделано 6.11 (Manual Deploy, `d5579e4`):
   `/shop`, `/offer`, `/account/shop`, `/ticket`, `/admin`, `/api/health` отвечают 200.

Сейчас в Render заданы только `ADMIN_TOKEN`, `DEMO_ACCOUNTS` (= `0`),
`NODE_VERSION`, `TRUST_PROXY`. Пункты 1–3 ещё не сделаны.

## Запуск локально
```bash
git clone https://github.com/stikech/New-akva-park-.git && cd New-akva-park-
cp backend/.env.example backend/.env   # ADMIN_TOKEN=любой-пароль, KASPI_PHONE=… для проверки оплаты
npm start                               # http://localhost:3000, админка /admin
npm test                                # 161 тест, Node.js ≥ 22
```
